# NOCTURNIA MUN WEBSITE

A responsive one-page website for Nocturnia MUN.

## Quick setup

Open `index.html` directly in a browser, or deploy the folder to:
- GitHub Pages
- Vercel
- Netlify
- Any static hosting provider

## Add your application links

Open `index.html` and search for:

`Replace each href="#" below with your application form link.`

Then replace the three `href="#"` values:
1. Executive Board
2. Organising Committee
3. Delegate

Example:
`href="https://forms.google.com/your-form"`
